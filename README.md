# 冒险者（Adventurer）

一个基于 HTML / CSS / JavaScript 开发的文字冒险游戏，融合探索、职业成长、生存与建造等多种玩法。

---

## 📖 项目简介

《冒险者》是一款轻量级前端文字冒险游戏，玩家将在一个动态生成的世界中探索、成长，并逐步解锁更多内容。

游戏包含：

* 地图探索
* 职业系统（公会）
* 生存机制
* 家园建造
* 科技研究
* NPC交互
* 随机事件

---

## 🚀 快速开始

1. 克隆项目：

```bash
git clone https://github.com/你的用户名/CODEX_AI.git
```

2. 打开项目目录：

```bash
cd CODEX_AI
```

3. 运行游戏：

* 直接打开 `index.html`（推荐使用浏览器打开）
* 或使用本地服务器（如 Live Server）

## 🎮 核心玩法

### 🗺️ 地图探索

* 固定地点：城镇、公会、家园
* 随机地点：怪物巢穴、盗贼据点等
* 支持动态移动与探索

### ⚔️ 职业系统

* 盗贼公会：暗影之握
* 法师公会：奥术之塔
* 战士公会：钢铁誓言
* 支持技能学习与跨公会发展（技能永久保留）

### 🏠 家园系统

* 建造房屋与设施（床、厨房、铁匠台、草药台）
* 提供功能性加成与制作能力

### 🔬 科技系统

* 通过科研台解锁新能力与玩法

### 🍖 生存系统

* 饥饿、口渴、精力、体温
* 影响角色状态与行动能力

### 🧑‍🤝‍🧑 NPC系统

* 村长（任务/剧情）
* 商人（交易）
* 公会导师（职业与技能）

### 💰 交易系统

* 支持购买与出售物品
* 所有物品具有价值属性

## 🛠️ 调试功能

| ---- | ------- |
| cash | +5000金币 |
| food | 饥饿值回满   |
