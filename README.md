# 冒险者 · BIGMCXM

使用 HTML、CSS 和 JavaScript 编写的浏览器文字冒险游戏，包含探索、职业成长、生存、交易与家园建造。A lightweight browser text-adventure game.

## 本地运行

```bash
git clone https://github.com/gura8390/BIGMCXM.git
cd BIGMCXM
python -m http.server 8000
```

访问 `http://localhost:8000/`。入口文件是仓库根目录的 `index.html`，无需安装 npm 依赖。

## 主要内容

- 探索城镇、公会、野外和其他地点。
- 加入职业公会，学习技能并成长。
- 管理生存需求、建造家园设施、研究科技。
- 与 NPC 对话和交易，处理随机事件与战斗。

这是个人文字游戏实验项目。所有玩法、存档和浏览器兼容性仍需单独验收。

## 文件结构

- `index.html`：页面入口。
- `css/`：样式文件。
- `js/`：游戏状态、地图、NPC、职业、家园等模块。
